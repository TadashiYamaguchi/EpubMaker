# EpubMaker

Windows専用の、複数巻まとめて処理できる自炊（スキャン）画像向け一括EPUB作成ツールです。
WPF (MVVMパターン) を採用し、コードビハインドを極力汚さないクリーンな設計を目指しています。

## 🎯 主な機能（予定）
- **ドラッグ＆ドロップ対応**：画面全体にZIP/RARファイル、またはフォルダを一括ドロップして読み込み。
- **エクスプローラー風管理**：複数巻のタスクを詳細一覧で管理。
- **手動リネーム機能**：英字のフォルダ名を、画面上のテキストボックスからその場で日本語に手動変更可能。
- **画像プレビュー＆ページ間引き**：
  - Pillow等のロジックを参考に、自動白紙ページ検出（除外フラグ）を実装予定。
  - 画面上のサムネイルをクリックすることで、不要なページ（広告や目次など）を手動で除外可能。
- **一括EPUB出力**：残ったページを自動連番リネームし、mimetypeルールに準拠したEPUB（ZIP）をワンクリックで一括生成。

## 🛠 技術スタック
- **言語**: C# (.NET 8.0 / 9.0)
- **UIフレームワーク**: WPF (Windows Presentation Foundation)
- **アーキテクチャ**: MVVM パターン
- **外部ライブラリ（予定）**: SharpCompress (ZIP/RAR解凍用)
