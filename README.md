# EpubMaker

Windows専用の、複数巻まとめて処理できる自炊（スキャン）画像向け一括EPUB作成ツールです。
WPF (MVVMパターン) を採用し、コードビハインドを極力汚さないクリーンな設計を採用しています。

## 🎯 主な機能

- **ドラッグ＆ドロップ対応**：巻リスト全体にZIP/RARファイル、または通常フォルダを一括ドロップして読み込み。
- **複数形式対応**：ZIP（Shift-JISファイル名にも対応）、RAR、通常フォルダに対応。フォルダドロップ時は直下にサブディレクトリがあれば自動的に複数巻として認識。
- **エクスプローラー風管理**：巻ごとに対象選択・巻名編集・ステータス・ページ数・出力ファイル名を一覧表示。
- **手動リネーム機能**：巻名をリスト上でその場編集可能。出力ファイル名（`[巻名].epub`）がリアルタイムに連動。
- **画像プレビュー＆ページ間引き**：
  - サムネイルクリックでページの除外/復活をトグル（除外中は半透明オーバーレイ表示）。
  - サムネイルダブルクリックでOS既定のビューアで原寸表示。
  - 白紙ページの自動検出（グレースケール化＋白色ピクセル比率判定）を巻単位で右クリック実行。
- **巻ごとの詳細設定**（右クリックメニュー）：
  - 出力画像フォーマット（JPG / WebP）の切り替え。
  - 読み進め方向（右開き=マンガ想定 / 左開き）の切り替え。
- **EPUB3準拠の一括出力**：
  - mimetypeの無圧縮・先頭エントリルールに準拠。
  - 固定レイアウト（`rendition:layout=pre-paginated`）でページ画像を配置。
  - `dcterms:modified`等の必須メタデータを付与。
  - `nav.xhtml`にtoc（目次）とpage-list（ページ番号ジャンプ）の両方を出力。
  - JPEG以外（PNG/BMP/TIFF/GIF/WebP）のソース画像は、選択中の出力フォーマットへ自動変換（既にJPEGの場合は再エンコードせずそのままコピー）。
- **出力先フォルダ選択・完了通知**：ネイティブのフォルダ選択ダイアログ、変換完了時のメッセージ表示。
- **終了時クリーンアップ**：アプリ終了時に一時展開フォルダを自動削除。
- **シングルファイル発行対応**：`Publish.bat`で自己完結型の単一exeを生成可能。

## 🛠 技術スタック

- **言語**: C# (.NET 8.0)
- **UIフレームワーク**: WPF (Windows Presentation Foundation)
- **アーキテクチャ**: MVVM パターン（コードビハインド不使用）
- **外部ライブラリ**:
  - [SharpCompress](https://github.com/adamhathcock/sharpcompress) — ZIP/RAR展開
  - [SkiaSharp](https://github.com/mono/SkiaSharp) — WebPの読み込み/書き出し（WPF標準では非対応のため）
- **共通部品**: `BindableBase`、`DelegateCommand`、`DragAndDropBehavior`、`ObservableCollectionEx`、`EnumToBooleanConverter`など、他のWPFアプリとの使い回しを前提に、あえて名前空間を付けずに実装。
